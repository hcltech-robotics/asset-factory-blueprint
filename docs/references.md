# References

Every cited work is recorded in the repository's `references.bib`, which the documentation build publishes beside the schema catalogue. Pages cite entries with pandoc syntax: an at-sign and entry key inside square brackets. The build renders each citation as a footnote and fails under `--strict` when a key does not resolve.
